1 Header CTA is the retention loop in one button — analyze the next game without navigating anywhere. D7 return is the metric it serves.

2 The summary is the largest type on the page. The report is a story, not a dashboard — if the hierarchy needs color to work, the hierarchy doesn't work.

7 Email capture renders after the full report — value first, signup second. The aha is never gated behind an account.

8 The share link is the growth loop — every report is a landing page for the next user. This line is what makes the $10k MRR math work at zero CAC.
